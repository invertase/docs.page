# Sentence structure

If you tell the reader to do something, state the circumstance, condition, or goal **before** the instruction so they can skip it when it does not apply.

Recommended: To delete the entire document, click **Delete**.  
Not recommended: Click **Delete** if you want to delete the entire document.

Recommended: If Docker is installed, run the configure command.  
Not recommended: Run the configure command if you have Docker.

Subject + verb + object. Keep the main subject and verb near the start. Prefer present tense.
