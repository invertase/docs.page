# Highlights

Most important points. Use this as the first pass; open another file only to substantiate a finding.

## Tone and content

- Conversational and friendly without being frivolous. → [tone.md](tone.md)
- Don't pre-announce unreleased features.
- Descriptive link text. → [links.md](links.md)
- Write accessibly. → [accessibility-and-global.md](accessibility-and-global.md)
- Write for a global audience. → [accessibility-and-global.md](accessibility-and-global.md)

## Language and grammar

- Second person: *you*, not *we*. → [person-and-voice.md](person-and-voice.md)
- Active voice: make clear who performs the action. → [person-and-voice.md](person-and-voice.md)
- Standard American spelling and punctuation.
- Conditions before instructions. → [sentence-structure.md](sentence-structure.md)
- Specific words: [word-list.md](word-list.md)

## Formatting, punctuation, and organization

- Sentence case on frontmatter `title` and on `##` headings. No `#` title in the body. Component `title` / `label` props are not headings. → [headings.md](headings.md)
- Sequences: numbered if `<Steps>`, a Markdown numbered list, or the live page already shows numbers. Don't flag those as unnumbered. Bullets for unordered sets. → [procedures.md](procedures.md), [lists-and-formatting.md](lists-and-formatting.md)
- Built-in MDX and GitHub alerts are already valid. Don't convert `<Info>` ↔ `> [!NOTE]`, `<TabItem>` → `<Tab>`, or markdown images → `<Image>`. → [html-and-markdown.md](html-and-markdown.md)
- Serial commas.
- Code-related text in code font; UI labels in **bold**. → [lists-and-formatting.md](lists-and-formatting.md)
- Unambiguous dates (`yyyy-mm-dd` or spelled-out month).

## Images

- Meaningful `alt`. Repo paths like `/assets/…`. → [formatting.md](formatting.md)
