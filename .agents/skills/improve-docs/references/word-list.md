# Word list (frequent flags)

Do not ingest a full dictionary. If a word on the page looks like a style issue, match it here. For anything else, skip it unless it hurts clarity.

| Avoid or limit | Prefer |
|---|---|
| *please*, *please note* | Direct imperative |
| *simply*, *easy*, *quickly* (in procedures) | Omit; describe the step |
| *let's*, *we* (for the reader's actions) | *you* or imperative |
| *click here*, *this document* | Descriptive link text |
| *e.g.*, *i.e.* | *for example*, *that is* |
| *etc.*, *and so on* | Open the list so it's clearly not exhaustive |
| *above* / *below* (position) | *preceding* / *following*, or name the thing |
| *utilize*, *leverage*, *commence* | *use*, *start* |
| *note that*, *it should be noted* | State the fact |
| *once* / *since* / *while* when they could mean time or cause | *after*, *because*, *although* as intended |
| *tl;dr*, other chat slang | Omit or write the point |

*Should* is weak in procedures; say what to do. *See* is the right verb for a cross-reference.

If a term is a product or API name, keep the publisher's established spelling.
