# Person and voice

## Second person

Address the reader as *you* / *your*, not *we*, *our*, or *us*.

Assume the reader is doing the task. Use *user* only for the end user of software the reader is building.

Recommended: The following sections describe how you can create a website.  
Not recommended: The following sections describe how we can create a website.

Recommended: Consider adding a description to your table.  
Not recommended: Let's add a description to our table.

If you tell the reader to do something, use the imperative (*you* is implied): Click **Submit**.

*We* / *our* is OK only when the antecedent is clearly the publishing organization (for example, support hours). Don't use it for the reader's actions.

Identify who *you* is (developer, admin) and stay consistent. An audience sentence near the top of the page helps.

## Active voice

Make the grammatical subject the person or thing that performs the action.

Recommended: Send a query to the service. The server sends an acknowledgment.  
Not recommended: The service is queried, and an acknowledgment is sent.

Passive is OK when you emphasize the object, de-emphasize the actor, or the actor does not matter (*The file is saved.* / *The database was purged in January.*).
