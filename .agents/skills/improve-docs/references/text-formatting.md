# Text-formatting summary

| Style | Use for | Not for |
|---|---|---|
| **Bold** (`**`) | UI labels, run-in list headings | Emphasis, code, new terms, fake callout titles |
| `_Italic_` | New terms on first definition, words-as-words, book titles, math variables | UI, code, fake emphasis in every paragraph |
| Underline | Don't. Link styling is the theme. | Emphasis |
| Code font (backticks) | Code, commands, filenames, HTTP codes, input | Product names, ordinary URLs that should be links |
| ALL CAPS | Placeholders (`PROJECT_ID`) | Shouting in prose |

Don't override font size or color inline (use `docs.json` theme). Don't use `&` for *and*. Punctuation stays outside link text.
