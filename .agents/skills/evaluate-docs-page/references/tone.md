# Voice and tone

Sound like a knowledgeable friend. Conversational, not slangy, cutesy, or dry.

## Avoid

- Buzzwords and unexplained jargon.
- Figurative language, metaphors, ableist phrasing.
- Placeholder phrases: *please note*, *at this time*.
- Starting every sentence with the same opener (*You can*, *To do*).
- Pop-culture references, humor that does not travel, exclamation marks.
- *Let's* do something.
- In procedures: *simply*, *it's easy*, *quickly*.
- Internet slang (*tl;dr*, *ymmv*).

## *Please*

Don't use *please* in instructions.

Recommended: To view the document, click **View**.  
Not recommended: To view the document, please click **View**.

## Pre-announcement

Don't document future features (*will soon support…*) unless legal has approved it. Write in present tense about what exists now.

## Politeness vs clarity

Useful information, said directly, beats entertainment.

| Too informal | About right | Too formal |
|---|---|---|
| This API is totally awesome! | This API lets you collect data about what your users like. | The API may enable the acquisition of information pertaining to user preferences. |
