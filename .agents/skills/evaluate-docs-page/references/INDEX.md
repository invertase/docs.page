# Topic index

Read **one** file when a finding needs a finer rule. Do not load this whole directory.

Skip HTML-site rules (custom CSS, link underlines, Javadoc, body `h1`, disabling copy on code). docs.page authoring: [Write](https://use.docs.page/authoring/write).

## First pass

| If you see… | Read |
|---|---|
| Unsure which rule applies | [highlights.md](highlights.md) |
| Slang, *please*, *simply*/*easy*, *let's*, *will soon* | [tone.md](tone.md), [general-principles.md](general-principles.md) |
| *we*/*our*, passive voice | [person-and-voice.md](person-and-voice.md) |
| Unnumbered steps in **source MDX** (not HTML-stripped tags), *should*, *run the following command* | [procedures.md](procedures.md), [general-principles.md](general-principles.md) |
| PascalCase MDX, GitHub alerts, Cards, CodeGroup, `<TabItem>` vs `<Tab>` | [html-and-markdown.md](html-and-markdown.md) |
| `#` title in the body, Title Case, *-ing* headings | [headings.md](headings.md) |
| *click here*, *this document* | [links.md](links.md) |
| Condition after the instruction | [sentence-structure.md](sentence-structure.md) |
| Wrong list type, missing code font, UI not bold | [lists-and-formatting.md](lists-and-formatting.md), [text-formatting.md](text-formatting.md) |
| *above*/*below*, walls of text, missing alt text | [accessibility-and-global.md](accessibility-and-global.md) |
| A disputed word | [word-list.md](word-list.md) |
