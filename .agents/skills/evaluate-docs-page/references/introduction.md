# Introduction and philosophy

This skill uses a house style applied to docs.page MDX (`docs.json` plus `docs/**/*.mdx`). Prefer docs.page mechanics and the publisher's `docs.json` conventions when they conflict with a guideline. Depart from a guideline when following it would make the page worse, then stay consistent.

Do not apply HTML-site advice (custom CSS, link chrome, Javadoc pages, body `<h1>`, click-to-copy opt-out). Those are not how docs.page works.
