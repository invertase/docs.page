---
title: Preview locally
description: Run a local preview of your docs.
---

Install the CLI, then preview.

<Steps>
<Step title="Install the CLI">
Run `npx docs.page`.
</Step>
<Step title="Open the preview">
Open the preview URL in your browser.
</Step>
</Steps>

<Info>
The preview watches the branch you already pushed.
</Info>

Clone `{owner}/{repo}` and set `EMAIL_ADDRESS` in the sample.

The API never returns a body on `204`.

```js
export default { name: 'acme' }
```
