# general-principles

Finish every Scan on the whole page. Classify each instance: violation, skip, or clean.

### unverifiable-claims

- **Scan:** `instant` / `instantly` / `immediately`; `best`, `fastest`, `never`, `always`, `ensure`, `guarantee`
- **Finding if:** unverifiable speed or quality; *ensure* / *guarantee* of security or uptime
- **Skip if:** a true product constraint (`never` as a rule); numbers with a cited source

### should

- **Scan:** `should`
- **Finding if:** `should` in a procedure or a required setting (*the value should be true*)
- **Skip if:** quoting a third party

### jargon

- **Scan:** `at the edge`, `shift left`, `post-mortem`, and other figurative jargon
- **Finding if:** the term is undefined on the page
- **Skip if:** the expansion or a link already appears

### inclusive

- **Scan:** `man-hours`, `crazy`, `sanity-check`, `dummy`, `he/she`, and violent or graphic metaphors
- **Finding if:** unnecessarily gendered, ableist, or violent language
- **Skip if:** a quoted error string shown in code font, with a plain-language gloss

### third-party

- **Scan:** claims about other products; blocks that look copied from another site
- **Finding if:** the page disparages a third-party product; or it copies text, images, code, or logos from other docs
- **Skip if:** a factual comparison the publisher owns
